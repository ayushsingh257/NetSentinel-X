# NetSentinel-X V2 — SOC Analyst Operations Guide

## Triage & Alert Workflow

1. **Live Alert Monitoring**: Observe real-time threat feed on the primary **SOC Dashboard**.
2. **AI Copilot Assistance**: Click **Ask AI Copilot** or use the floating prompt button to request context-aware threat reasoning.
3. **Investigation Story**: Open the **Threat Investigation Workspace** to view multi-event attack timelines and root cause analysis.
4. **MITRE ATT&CK Mapping**: Check technique correlation on the **MITRE ATT&CK Matrix Grid**.
5. **Attack Graph Traversal**: Inspect visual attack chains on the **Interactive Attack Graph**.

---

## Threat Hunting & SOAR Execution

1. **Threat Hunting**: Open the **Threat Hunting Workspace**, enter IOC values (IP/Domain/Hash), or run natural language hypothesis queries.
2. **SOAR Playbooks**: Access **Workflow Automation & SOAR**, review automated playbooks, and approve pending analyst actions in the approval queue.
3. **Incident Escalation**: Manage 7-state incident cases (NEW -> CLOSED) in the **AI Incident Desk**.
